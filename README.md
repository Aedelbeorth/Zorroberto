Zorroberto es un tema personalizado para Firefox que combina:

    Una barra superior unificada

    Una barra lateral de marcadores autoocultable

    Una caja de URL flotante

Instalación
1. Instalar fx-autoconfig ( https://github.com/MrOtherGuy/fx-autoconfig )

Antes de usar Zorroberto, instala fx-autoconfig siguiendo las instrucciones del repositorio oficial:
fx-autoconfig

2. Abrir tu perfil de Firefox

Localiza la carpeta de tu perfil. Suele tener un nombre similar a:
Código

C:\Users\TU_USUARIO\AppData\Roaming\Mozilla\Firefox\Profiles\xxxxxxx.default-release

3. Copiar los archivos del repositorio Zorroberto dentro de tu carpeta de perfil


Reinicia Firefox para aplicar los cambios.

Installation
1. Install fx-autoconfig ( https://github.com/MrOtherGuy/fx-autoconfig )

Before using Zorroberto, install fx-autoconfig following the instructions from the official repository:
fx-autoconfig

2. Open your Firefox profile folder

Locate your Firefox profile directory. It usually looks like:
Código

C:\Users\YOUR_USER\AppData\Roaming\Mozilla\Firefox\Profiles\xxxxxxx.default-release

3. Copy the files from the Zorroberto repository into your Firefox profile folder


Restart Firefox to apply the changes.

# Zorroberto
Zorroberto is a custom Firefox theme that combines a unified top bar, an auto-hiding bookmarks sidebar, and a floating URL box.
Zorroberto es un tema personalizado para Firefox que combina una barra superior unificada, una barra lateral de marcadores autoocultable y una caja URL flotante.
